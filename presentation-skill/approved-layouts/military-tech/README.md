**注意：背景本身是 PNG；簡報標題、章節編號、日期、Logo、內容文字、圖表與表格，必須由 PowerPoint 原生物件疊加，不能直接燒錄在背景圖片中。**

## PowerPoint 使用要求

1. 使用原圖作為全頁背景，按原始 16:9 近似比例等比裁切或填滿，勿拉伸變形。
2. 封面與章節頁的所有字、數字、頁碼及 Logo 保持可編輯、可刪除。**不得將完整投影片扁平化成圖片。**
3. 內容頁應使用純白區域放入原生文字、表格、圖表及圖片。標題放於橫幅以下或適當的可讀性區域，確保不受右上圖像干擾。
4. 背景中的裝備以使用者批准的視覺為準；後續若更換實際產品設備，必須使用提供的正確產品照片或經核准的版本。
5. 此三張視覺僅代表「軍事科技」系列，不取代企業簡報／警政／消防等其他類型封面。所有新增可編輯內容仍需遵守 CIS v3.2。
6. 本套背景圖片的使用不代表影片、產品規格或軍警設備的性能聲稱。

## PowerPoint 母片及 Logo 管理（強制規則）

**背景 PNG 保持無 Logo、無標題、無編號。正式 PowerPoint 的 Logo 必須在投影片母片（Slide Master）或其版面配置（Slide Layout）中統一設置，禁止每頁重複插入。**

- **封面版面配置**：依 CIS 與封面構圖設定適當的官方 Logo 版本和位置；主標題等文字由可編輯佔位符提供。
- **章節過渡版面配置**：Logo 出現與否、尺寸及位置由該版面配置決定，避免同一張背景與其他版面重複疊加。
- **內容版面配置**：右上科技橫幅與左側標題區需保持可讀性；Logo 視 CIS 規範於母片／版面配置中設定，不得出現在背景 PNG。
- Logo 必須取自 `01_Logo/` 官方素材，不能重繪、AI 生成或更改品牌規範。
- 產生的投影片不得另外加入第二個 Logo；修改母片的 Logo 時，套用該版面配置的頁面應同步更新。
