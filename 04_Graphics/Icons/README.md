# BXR Presentation Skill — Icon Library

## Asset groups
- `04_Graphics/Icons/BXR_Icon_*.svg`: existing BXR corporate SVG symbols; **unchanged**.
- `04_Graphics/Icons/Additional/Icon_*.png`: 17 newly uploaded PNG icons, renamed consistently. These are **supplemental**, not automatically official CIS artwork.
- `04_Graphics/Icons/Illustrations/BXR_Illustration_*.png`: 2 large PNG illustrations; do not present as compact monochrome line icons.

## Selection and usage
1. Read `icon-catalog.csv` to find related tags before selecting an icon; prefer official BXR SVG where equivalent.
2. Do not mix unrelated line weights, illustrative 3D effects or fill styles in one slide; evaluate preview before finalizing.
3. Icons are content-level elements **not Slide Master/Logo elements**. Corporate logos, theme colors, fonts and title styles belong in PowerPoint master/layout/theme.
4. Avoid stretching PNG, respect transparency, keep crisp resolution, and use editable SVG vector shapes when PowerPoint can preserve them. Avoid claiming PNG artwork is recolorable.
5. Icon names and categories are based on filenames, not visual inspection; two soldier and two target assets are identified as 01/02 without inventing distinctions.
6. If the sources are externally licensed, verify rights before public distribution or reuse.

## Naming
`Icon_<Concept>[_NN].png` for standalone PNG icons and `BXR_Illustration_<Concept>.png` for larger illustrations. Existing official `BXR_Icon_<Concept>.svg` names remain unchanged.
