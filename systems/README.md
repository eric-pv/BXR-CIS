## 為什麼花費紀錄要獨立

- 日常動線不同：費用是出差／參展後登打與請款；CRM 是展場掃名片與業務追蹤。
- 敏感度不同：花費金額、付款對象的銀行帳號不應與業務名單共用同一套存取範圍。
- 定位單純：只是記錄花費、產出請款單給財務，正式帳務仍在財務部門。
- CRM 之後要開放「客戶自填表單」給展場訪客（免登入），不能與內部花費紀錄放在同一個應用程式。

CRM 使用獨立的 `index.html` 前端與 Supabase 專案；活動花費紀錄以 Google Sheet 優先（Supabase 為備選），兩者互不直接寫入，ROI 透過活動名稱對應彙總資料。
兩邊都會有「展覽」主檔；是否要同步（例如以展覽名稱對應）屬於**待決事項**，見各規格的「尚未完成」。
